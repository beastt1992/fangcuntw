# 方寸 · FANGCUN

用骨架與參數設計整套繁體中文字型。

- **13,104 字內建**（Big5 常用＋次常用，其中大部分採台灣字形）
- **完全離線**：字庫與字型引擎都內嵌在 index.html 裡，不連任何外網
- 八根設計軸一拉，一萬三千字同時改變
- 可匯出真正能安裝的 OTF

## 部署

整個資料夾丟上任何靜態主機就好（Netlify 直接拖曳、Vercel、GitHub Pages 都行）。

必須用 **https**（或 localhost）才會變成可安裝的 PWA——service worker 在 `file://` 下不會註冊。
直接雙擊 index.html 也能用，只是不能安裝、沒有離線快取。

```
fangcun/
├── index.html            ← 3.0 MB，字庫和引擎都在裡面
├── manifest.webmanifest
├── sw.js                 ← 第一次載入後整包快取，之後離線可用
├── icon.svg
├── icon-192.png / icon-512.png
└── icon-mask-192.png / icon-mask-512.png
```

## 用法

| | |
|---|---|
| **工作台** | 左邊八根設計軸、中間字樣格（可搜尋分頁）、右邊放大檢視與拖曳編輯 |
| **展示** | 每一筆單獨上色、七組調色盤、可存 SVG / PNG |
| **匯出 OTF** | 會問「字數,精度」，直接按確定就是全部字、最高精度 |
| **全部還原** | 退回內建字庫的原始狀態，你的調整全部清掉 |
| **專案存檔** | 只存你改過的部分，檔案很小 |
